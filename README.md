# Дім і Ремонт — інтернет-магазин

Статичний сайт + Cloudflare Worker. Деталі розгортання — у DEPLOY.md.

- `config.py` — назва, контакти, домен, самовивіз
- `data/` — товари з каталогів постачальника
- `build.py` — генерує сторінки в `site/`
- `worker/worker.js` — API: замовлення в Telegram, довідники Нової пошти та Укрпошти
