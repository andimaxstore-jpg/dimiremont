# Дім і Ремонт — інтернет-магазин

Статичний сайт + Cloudflare Worker. Деталі розгортання — у DEPLOY.md.

- `config.py` — назва, контакти, домен, самовивіз
- `data/` — товари з каталогів постачальника
- `build.py` — генерує сторінки в `site/`
- `worker/worker.js` — маршрути сайту; API: замовлення (база + Telegram), довідники Нової пошти та Укрпошти
- `worker/render.js` — сторінки вітрини, які Worker збирає з бази D1
- `worker/admin-api.js`, `worker/auth.js`, `worker/db.js` — бек-офіс: API, вхід за паролем, схема бази
- `web/admin/` — інтерфейс бек-офісу (відкривається на /admin/)
- `data/seed.json` — початкові дані для порожньої бази (генерує build.py)
