# Розгортання «Дім і Ремонт» на Cloudflare

Сайт = Cloudflare Worker `dimiremont`: статичні сторінки з `site/` + серверний код `worker/worker.js` (прийом замовлень, довідники НП/Укрпошти).

## Збірка
    python3 build.py          # генерує site/
    npx wrangler deploy       # викладає Worker (потрібен Node.js 18+ і вхід: npx wrangler login)

## Секрети Worker (Cloudflare → Workers & Pages → dimiremont → Settings → Variables and Secrets → Add → Secret)
- ADMIN_PASSWORD     — пароль входу в бек-офіс https://dimiremont.com.ua/admin/ (довгий, 12+ символів)
- TELEGRAM_BOT_TOKEN — токен бота від @BotFather
- TELEGRAM_CHAT_ID   — ваш числовий id (дізнатися: напишіть @userinfobot) або id групи; кілька — через кому
- NP_API_KEY         — ключ API Нової пошти (кабінет НП → Налаштування → Безпека → Ключ API)
- UP_TOKEN           — bearer-токен Укрпошти (видається за договором); без нього клієнт вписує відділення Укрпошти вручну

Перевірка: відкрийте /api/health — побачите, які секрети та база підключені (`db`, `admin`).

## База D1 і бек-офіс
Товари, категорії, характеристики, фільтри, сторінки, налаштування та замовлення зберігаються в базі Cloudflare D1 `dimiremont-db` (binding `DB`).
- База створена в Cloudflare (D1 → `dimiremont-db`), її ID записано в `wrangler.jsonc`.
- Таблиці створюються, а товари з `data/seed.json` заливаються автоматично при першому запиті до сайту. Далі джерело правди — база, а не файли в репозиторії.
- Фото, завантажені в адмінці, зберігаються в тій самій базі й віддаються за адресою `/media/<id>`.
- Резервна копія: адмінка → Налаштування → «Завантажити резервну копію».
- Якщо базу не підключено, сайт працює як раніше — зі статичних сторінок `site/`.


## Автопублікація
Воркер підключено до GitHub (Cloudflare Workers Builds): кожен push у гілку `main` запускає `npx wrangler deploy`.
Перед комітом запускайте `python3 build.py`, бо `site/` зберігається в репозиторії вже зібраним.

## Особистий кабінет покупця
- Сторінка `/kabinet.html`: вхід за телефоном або email + пароль, який покупець придумує сам. Паролі зберігаються лише як хеш (PBKDF2), їх не видно ніде.
- Вкладки: «Мої замовлення» (статуси ті самі, що в адмінці, номер ТТН із посиланням на трекінг НП), «Особисті дані» (контакти й доставка за замовчуванням, яка підставляється в кошик), «Збережені товари» (сердечко на картках і сторінці товару).
- Замовлення, оформлене після входу, прив’язується до кабінету автоматично. Замовлення, оформлене в цьому ж браузері до реєстрації, додається само; інші — за номером замовлення і телефоном.
- Адмінка → «Клієнти»: усі кабінети, їхні замовлення, збережені товари, схожі замовлення без кабінету (можна прив’язати), зміна пароля клієнту.
- Таблиці `customers`, `wishlist`, `secrets` і колонка `orders.customer_id` створюються автоматично (патч `patch_accounts_v1` у worker/db.js).

## Сторінка «Як працювати з самоклеючими товарами для ремонту»
- Адреса `/yak-kleity-samokleiuchi-materialy.html`, у меню «Каталог → Покупцям» і в підвалі.
- Текст-заготовка: `data/guide_page.html` (build.py робить з нього `data/guide_page.json`). Worker додає сторінку в базу один раз (патч `patch_guide_v1`), далі її редагують в адмінці → Сторінки.
- Розділи мають id за адресою категорії (`<h2 id="plytka">`), тому на сторінках цих категорій і їхніх товарів з’являється посилання «Як монтувати: покрокова інструкція».
- Розділ «Часті запитання» (H2, питання — H3) автоматично стає розміткою FAQPage для Google; при 4+ заголовках H2 сторінка отримує зміст.

## Сторінка «Гарантія та повернення»
- Адреса `/garantiia-ta-povernennia.html`, у меню «Каталог → Покупцям» і в підвалі. Редагується в адмінці → «Сторінки».
- Текст-заготовка: `data/returns_page.html` (build.py робить `data/returns_page.json`). Worker додає сторінку в базу один раз (патч `patch_returns_v1`) і дописує посилання на неї в розділ «Повернення» сторінки «Доставка і оплата», якщо його там ще немає.
- Посилання з картки товару (під доставкою) і з кошика (під кнопкою замовлення) знаходяться автоматично: сторінка з адресою `garantiia-ta-povernennia` або з назвою, де є слово «повернення». Вона ж іде в розмітку Google як `merchantReturnLink`.
